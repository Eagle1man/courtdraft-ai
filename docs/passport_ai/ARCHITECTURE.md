# ARCHITECTURE — паспорт-ИИ

## Принцип

Паспорт-ИИ — дополнительный способ подготовки существующего
`00-ПАСПОРТ-ДЕЛА.json`. Старый сценарий «готовый JSON → проверка → иск → DOCX»
не меняется и не требует LLM.

## Компоненты

| Компонент | Назначение |
|---|---|
| `models.py` | Типизированные модели документов, фактов, конфликтов, полей |
| `llmclient.py` | Единый интерфейс LLM; по умолчанию FakeLLM |
| `reader.py` | Адаптер к `CaseDocument`/`DocumentChunk` БД |
| `classify.py` | Классификация правилами, LLM только при неоднозначности |
| `extract.py` | LLM-кандидаты + детерминированный добор, quote/value-gate |
| `reconcile.py` | Сопоставление, хронология, Decimal-арифметика, конфликты |
| `assembler.py` | Сборка реального паспорта по `field_map.json` |
| `validators.py` | Адаптер к `CasePassport` и `validate_invariants()` |
| `service.py` | Оркестратор, сохранение этапов, возобновление, подтверждение |

## Контракт-первый подход

Имена полей паспорта не зашиты в код. Они приходят из:
- `artifacts/passport/passport_contract.json` — обнаруженный контракт;
- `artifacts/passport/field_map.json` — роли, указатели, типы, derived-правила.

## Анти-галлюцинационные гейты

1. **quote-gate**: цитата LLM должна дословно найтись в тексте документа.
2. **value-gate**: значение должно подтверждаться этой цитатой (для денег/дат
   выполняется программное пересчётывание).
3. Неподтверждённый факт сохраняется как `UNSUPPORTED`, но исключается из паспорта.
4. Деньги — только `Decimal` внутри и `int` копеек на границе паспорта.
5. Конфликты не разрешаются молча; поле остаётся пустым, варианты показываются человеку.
6. Маркеры `[... — по данным дела]` считаются отсутствием, а не выдуманным значением.

## Подтверждение

`confirm()` не пишет файл напрямую. Роутер:
- повторно вызывает `CasePassport.model_validate` и `validate_invariants`;
- отказывает при P0;
- создаёт бэкап прежней записи;
- сохраняет через `CasePassportRepository`.

## Изоляция

Все `/passport-ai/*` endpoints принимают `student_code` и проверяют владельца
дела теми же правилами, что и существующие case endpoints.
