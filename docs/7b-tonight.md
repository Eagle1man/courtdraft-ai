# Ночной прогон 7B на стенде (05–06.11.2026)

Договорённость: днём тест студентов идёт на **1.5B**, ночью стенд
переключается на **7B** ради замера скорости и качества.

## Почему qwen2.5:7b, а не Vikhr

На стенде уже лежит `wavecut/vikhr:7b-instruct_0.4-Q4_1`, но это
completion-модель без chat-шаблона, а сервис обращается к `/api/chat`.
Кроме того, Vikhr — другое семейство: сравнение с 1.5B смешало бы два
фактора (размер и саму модель), и вывод «7B лучше» был бы неверным.
`qwen2.5:7b` — та же семья, что и 1.5B, поэтому меняется только размер.

## Железо, на котором это будет идти

| Параметр | Значение |
|---|---|
| GPU | нет (драйвера NVIDIA на ВМ нет, Ollama считает на CPU) |
| CPU | 4 ядра |
| RAM | 7,5 ГБ, свободно ~5,6 ГБ |
| Модель 7B Q4 | 4,7 ГБ |

Замер 1.5B на этой же машине: обработка промпта ~55 ток/с, генерация
**9,6–11,9 ток/с**. Для 7B ожидается ~2–2,5 ток/с, то есть проект из
6 разделов — **40–90 минут**. Это разведка, а не рабочий режим.

## Порядок

1. Убедиться, что студентов нет (в базе нет `PENDING`/`RUNNING` заданий).
2. `bash scripts/vm_profile_7b.sh` — модель, параметры, перезапуск.
3. Прогнать 2–3 дела (те же, что днём — иначе сравнивать нечего).
4. Снять цифры:

   ```bash
   cd backend
   .venv/bin/python -m scripts.test_status --hours 3
   journalctl -u ollama --since -2h | grep -E "prompt eval time|eval time"
   ```

5. Утром вернуть 1.5B: `bash scripts/vm_profile_15b.sh`.

## Что считать результатом

- **время на проект** (из `jobs`: `started_at` → `finished_at`);
- **скорость** (токены/с из журнала Ollama);
- **обрывы** (`[текст оборван по лимиту ответа]` в разделах);
- **замечания проверки**: сколько `UNSUPPORTED_CLAIM`, `INCOMPLETE`,
  `JURISDICTION_MISMATCH` на проект;
- **память**: не ушла ли машина в своп (`free -h`, `vmstat 1 5`).

Успех ночного прогона — не «стало красивее», а: проектов не оборвало,
выдуманных чисел меньше, время укладывается в приемлемое. Если 7B не
влезает в железо, это тоже результат: тогда 7B имеет смысл только на
машине с GPU, а на стенде остаётся 1.5B с базой знаний по нормам.
