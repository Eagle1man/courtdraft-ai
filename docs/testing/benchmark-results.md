# Результаты замеров

## 06.11.2026 — извлечение таблиц DOCX

**Что измерялось:** сколько содержимого возвращает новое извлечение
таблиц на реальных документах из снимка теста (503 файла, 471 DOCX).

**Скрипт замера:** обход `cases/originals`, разбор через
`app.ingestion.extract.extract_text`; «старое поведение» — тот же файл,
но только абзацы (`python-docx`, без таблиц). Сравнение по суммам:
`app.drafting.numeric_guard.extract_money`.

| Показатель | Значение |
|---|---|
| Документов DOCX | 471 |
| Из них с таблицами | **151 (32 %)** |
| Строк таблиц | **864** |
| Документов, где появились суммы, которых раньше не было | 7 |
| Сумм, которых раньше не было в тексте | **21** |
| Сбоев разбора | 0 |

**Вывод:** треть документов содержит таблицы, и всё их содержимое
раньше не попадало в пакет доказательств. Числа в таблицах часто
дублируются в тексте, поэтому новых сумм немного (21), но пропадала
**структура**: какая сумма к какой графе и периоду относится. Для
расчётов это важнее самих чисел.

**Ограничение замера:** сравнивались только суммы. Даты и реквизиты в
таблицах не считались; структура («строка ↔ графа») не оценивалась —
для этого нужен gold-набор (этап 8).
