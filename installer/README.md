# Установщик CourtDraft AI (Windows)

Каркас T7: сборка установщика **без весов моделей**. Модели скачиваются онлайн или импортируются с флешки при первом запуске.

## Требования для сборки (шаг 8 плана)

- Python 3.12 x64 (`py -3.12`)
- Inno Setup 6 (`ISCC.exe`)
- `installer/vendor/winsw.exe` (WinSW 2.x x64, MIT) — не коммитится
- `installer/vendor/python-3.12.10-embed-amd64.zip` (python.org) — не коммитится
- опционально: `installer/vendor/OllamaSetup.exe` (для офлайн-установки Ollama)

Если чего-то нет — сборку не запускать: скачать вручную с официальных источников.

## Сборка

```powershell
cd D:\courtdraft-ai
.\installer\build.ps1 -Version 0.1.0
```

Результат: `installer/dist/CourtDraftAI-0.1.0-x64.exe`. Каталоги `stage/`, `dist/`, `.build-venv/` генерируются и игнорируются git.

## Что делает установщик

- Определяет железо (`hardware_profile.py`) и записывает рекомендации в `hardware.json`.
- Режимы: служба Windows для всех пользователей (порт 8081) или портативно для текущего пользователя (порт 8080).
- Первый запуск (`first-run.ps1`): быстрая/качественная модель по профилю (Ollama pull), импорт GGUF с флешки или API DeepSeek Flash (ключ из файла через `set_openai_key.py`, ключ не печатается).

## Ограничения

- В установщик не входят веса моделей (`*.gguf`, `*.safetensors`).
- Приёмка — на чистой Windows 10/11 x64 (T9), человеком. Подпись кода — человеком.
- `git push` и публикация — не выполняются автоматически.
